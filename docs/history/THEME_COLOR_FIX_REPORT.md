## 🎨 Theme Color Mapping

The ThemeManager provides these color getters:

| Getter | Returns | Usage |
|--------|---------|-------|
| `getGradientStart()` | Primary gradient start | Buttons, accents |
| `getGradientEnd()` | Primary gradient end | Gradient backgrounds |
| `getGradientMid()` | Mid-point of gradient | Secondary elements |
| `getGradientOverlayText()` | White overlay for dark themes | Text on colored backgrounds |
| `getTextPrimaryColor()` | Main text color | Headings, labels |
| `getTextSecondaryColor()` | Secondary text color | Subtitles, metadata |
| `getCardBackgroundColor()` | Card surface color | Card backgrounds |
| `getScreenBackgroundColor()` | App background | Screen backgrounds |
